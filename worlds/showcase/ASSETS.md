## Dropping in your own splat

Any `.spz`, `.ply` (3DGS), `.splat` or `.ksplat` file works: copy it into `assets/` and
point an entity at it, e.g.
`{ "id": "room", "kind": "splat", "src": "assets/room.spz", "transform": { "rotation": [180, 0, 0] } }`.
Many captures are stored Y-down (OpenCV convention); a 180° turn about X stands them up.
Splat worlds render on WebGL2 (Spark.js); `?renderer=auto` picks it for you.
